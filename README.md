## 仓库说明

mcmod的签到助手,帮助你每天自动签到窜门和推荐模组

## 配置文件

初次使用会生成默认的配置文件,配置文件如下:

| 键名 |   默认设置   | 参数类型 |     备注      |
| :----: |:--------:|:----:|:-----------:|
| username |   root   | 字符串  |    用户名字     |
| password | root1234 | 字符串  |     密码      |
| Visited_id |    2     |  整数  |  要拜访的用户id   |
| pushed_mod_id |    2     |  整数  |  要推荐的模组id   |
| random_time_interval|   1,10   |  数组  | 随机暂停的时间间隔范围 |
| max_retries |    5     |  整数  |   最大重试次数    |
| cookie_refresh |    30    | 整数  | 刷新cookie的时间 |
